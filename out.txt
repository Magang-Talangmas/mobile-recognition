Nah, **agar jadwalnya benar-benar muncul angka (seperti 08:00 - 17:00)**, kita perlu membuat 1 data jadwal di Supabase.
Boleh tolong jalankan *query* SQL ini di **SQL Editor Supabase**-mu?

```sql
-- Hapus data dummy lama jika ada yang nyangkut (opsional)
DELETE FROM work_schedules WHERE employee_id = (SELECT id FROM employees WHERE email = auth.jwt()->>'email' LIMIT 1);

-- Masukkan jadwal Reguler Pagi untuk akunmu saat ini
INSERT INTO work_schedules (
    employee_id, 
    name, 
    shift_start, 
    shift_end, 
    check_in_time, 
    check_out_time, 
    tolerance_minutes, 
    is_active
) 
VALUES (
    (SELECT id FROM employees ORDER BY created_at DESC LIMIT 1), -- Mengambil ID akun yang barusan kamu buat (gibran)
    'Reguler Pagi', 
    '08:00:00', 
    '17:00:00', 
    '07:00:00', 
    '19:00:00', 
    15, 
    true
);
```
